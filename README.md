# Manufacturing_Analytics_Dashboard
Power BI Manufacturing Analytics Dashboard for monitoring production performance, rejection analysis, wastage tracking, machine efficiency, employee performance, and operational KPIs in a label manufacturing environment.
AXON Labels Manufacturing Dashboard
Overview

This project is a Power BI Manufacturing Analytics Dashboard developed to monitor and analyze key production metrics within a label manufacturing business. The dashboard provides management with a centralized view of production output, quality performance, wastage levels, machine efficiency, employee performance, and delivery status.

The goal is to enable data-driven decision-making by identifying production bottlenecks, high rejection areas, underperforming machines, and operational trends.
